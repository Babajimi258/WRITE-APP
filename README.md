# WRITE

Mobile-first songwriting app for GitHub Pages.

## Upload to GitHub Pages
Upload these files directly into the repository root:
- `index.html`
- `write-logo.png`
- `write-mark.png`
- `icon-192.png`
- `icon-512.png`
- `apple-touch-icon.png`
- `manifest.webmanifest`

## Current UX
- Light / Dark / System theme
- German / English
- Favorites, archive and swipe actions
- Autosave
- Beat player with seek, ±10 seconds, volume, BPM/key editing and analysis
- Compact sticky beat controller while writing lyrics
- All lyric sections visible together with subtle separation
- Text duplication uses the selected text; without a selection it duplicates the whole current section
- Line reorder, undo/redo and repeated hooks
- Recording sketches with rename, play/pause, stop, seek, waveform, time/date and a small take note

Song recognition is prepared for a secure AudD proxy. Do not put a private API token directly into public GitHub Pages code.
